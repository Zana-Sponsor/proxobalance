# ڕاپۆرتی گۆڕانکاری و تێستی پڕۆکسۆ

**نوێکردنەوەی ٢٠٢٦-١٠-١٩:** وێنەی نمونە بووە سکرینشۆتی ڕاستەقینە، هەڵبژاردنی ستایل چاک کرا و فۆتەری هەموو ١٢ شێوە بە ٩٦ حاڵەت پشکنرا. [٧٢ وێنە، ئەنجامە نوێکان و APK](../evidence/proxolink-examples-2026-10-19/README.md). ژمارە و APK ـەکانی خوارەوە بەڵگەی وەشانی پێشوون.

## چی گۆڕا؟

| بەش | گۆڕانکاری |
|---|---|
| Auth و AppBar | بەرزی AppBar بووە ٥٦dp، لۆگۆ ٨٤×٢٤، بۆشایی ژێری ٤٠dp، ناونیشان ٢٠ و دەقی خانەکان ١٤. |
| دروستکردنی هەژمار | ناو، ئیمێڵ، وشەی نهێنی و دووبارەکردنەوەی لە یەک فۆڕمدان؛ OTP شاشەی جیاوازە. ژمارەکردنی هەنگاوەکان نییە. |
| ئایکۆن | وێنەی 3D بۆ هەژمار و پشتڕاستکردنەوە زیاد کراوە؛ قەبارەی پیشاندان ٦٤×٦٤dp ـە. |
| ئیمێڵ و مۆبایل | گواستنەوە بە ئەنیمەیشنە، فۆڕمەکان لەسەر یەکتر دەرناکەون، زانیاریی نووسراو دەمێنێتەوە. |
| ژمارەی مۆبایل | ئاڵای عێراق و ‎+964 لە کاتی نووسینیش دیارن. |
| OTP | خانەی ٤٨×٥٦، گۆشەی نەرم ١٦، ژمارەکان لە ناوەڕاست؛ لە شاشەی تەسکدا خانەکان دابەش دەبن. ژمارەکانی `١٢٣٤٥٦`، `۱۲۳۴۵۶` و `123456`، لە نووسین و پەیستکردندا قبووڵ دەکرێن و بۆ ناردن دەبنە `123456`. |
| دوگمەکان | ستایلی هاوبەش بە گۆشەی نەرم ١٨dp؛ دوگمەی سەرەکی Auth کەمترین بەرزی ٥٠dp. دوگمەی وەرگرتنی خەڵاتی ئەرک، چالاککردنی کۆدی فاوچەر و چالاککردنی فاوچەری تەرخانکراو کەمترین بەرزی ٤٨dp و هەمان گۆشەی ١٨dp ـیان هەیە. لینکی دەقی Auth کەمترین ناوچەی دەستلێدان ٤٤×٤٤dp. |
| گۆڕینی شاشە | گواستنەوەی ڕێڕەو ٣٢٠ms و تاب ٢٨٠ms؛ ڕێکخستنی کەمکردنەوەی جووڵەی سیستەم ڕەچاو دەکرێت. ئەمانە ماوەی دیزاینن، نە ئەنجامی پێوانەی فریم. |
| ڕیفرێش | دەقی «نوێدەکرێتەوە» لە تەنیشت سووڕێنەرەکە دەردەکەوێت؛ داواکاریی دووبارە یەک دەخرێت. |
| سپڵاش | باکگراووندی سپی، تیشکی شین و لۆگۆی هاوسەنگ، لەگەڵ ئەنیمەیشنی دەستپێک. |
| چوونەژوورەوە | هەژماری پێشوو ڕاستەوخۆ دەچێتە ئەپ؛ پێویستی بە ئامادەکردنی پڕۆفایل نییە. |
| ئاگاداریی باکگراووند | ئاگاداریی Android لە دەرەوەی ئەپ نیشانی P ـی پڕۆکسۆ و ڕەنگی شین بەکار دەهێنێت. ئاگاداریی ناوخۆیی و data-only لۆگۆی گەورەشیان هەیە. |
| کێشەی ئاگاداری | ونبوونی ئاگاداریی data-only لە foreground و ونبوونی مەبەستی کلیک لە کاتی داخراوبوونی ئەپ چاک کراون. |
| نمونەی لینکی ڤیدیۆ | «بینینی نمونە» وێنەی ڕوونکردنەوە و نموونەی لینک دەکاتەوە، بێ چاوەڕوانی ئینتەرنێت. |
| نمونەی دروستکردنی پەڕە | وێنەی نمونە بۆ پەڕەی پەیوەندی، داواکردن و داگرتن؛ وێنەکان پێشوەختە بار دەکرێن. |
| فێرکاری | «بینینی فێرکاری» لینکی دانراوی ئەدمین لە Supabase دەخوێنێتەوە؛ یوتوب یان لینکی HTTPS ـی دیکە. گۆڕینی لینک پێویستی بە APK ـی نوێ نییە. |

## ئەنجامی تێست

- **٨٨٠ تێستی Flutter سەرکەوتوون**؛ تێستی فۆڕم، پشکنینی دروستی زانیاری، OTP، چوونەژوورەوە، دۆخی چاوەڕوانی، کلیکی دووبارە، ڕیفرێش، ژیانی شاشە و ڕووکار لەخۆ دەگرن. لۆگی کۆتایی بە `+880: All tests passed!` تەواو بووە.
- **٥ تێستی نوێی OTP** نووسین و پەیستکردنی ژمارەی عەرەبی، فارسی/کوردی، لاتینی و تێکەڵ پشکنین دەکەن. کۆدی تەواو یەک جار بانگی پشتڕاستکردنەوە دەکات؛ نوێبوونەوەی ڕووکار ژمارەکان ناسڕێتەوە و بانگەکە دووبارە ناکاتەوە. پەیستکردن لە ناوەڕاستی کۆدیش ژمارەکانی پێشوو دەپارێزێت.
- **١٧٩ تێستی سێرڤەر** لە GitHub سەرکەوتوون؛ پشکنینی داتابەیس و Edge Function ـەکانیش تێپەڕیون.
- **١٥٠ دۆخی ڕووکار**: ٢٥ شاشە/دۆخ × سۆرانی، عەرەبی، بادینی × دوو ڕێکخستنی شاشە. **٢٠٠ سکرینشۆت** لەگەڵ پێوانەی **١٠٬٨١٢** بەشی ڕێکخراوی ڕووکار؛ هیچ هەڵەی ڕێکخستنی ڕووکار تۆمار نەکراوە.
- **٢٤ سکرینشۆتی نمونەکان**: لینکی ڤیدیۆ و سێ جۆری پەڕە، بە هەمان سێ زمان و دوو قەبارە. کۆی وێنەکانی ئەم تێستانە **٢٢٤** ـە.
- لە Auth هیچ دەقێک بەهۆی سنووری هێڵەوە نەبڕاوە. ١٨ کورتکردنەوەی پێشووی دەق لە پوختەی ئاگاداری، ناسنامەی ڕیکلام و ناونیشانی ئەرک لە شاشەی تەسکدا ماون و لە ڕاپۆرتەکە دیار کراون.
- **١٢ دۆخی ئەرک و فاوچەر** لە سێ زمان، بە پانی ٣٩٣dp و دەقی ئاسایی، هەروەها پانی ٢٨٠dp و دەقی دوو هێندە، تێپەڕیون. دوای ڕێکخستنی دوگمەی چالاککردنی فاوچەری تەرخانکراو، هەموو **٦ دۆخی فاوچەر** دووبارە تێپەڕین؛ هیچ هەڵەی ڕێکخستنی ڕووکار یان داخستنی شاشە تۆمار نەکراوە. ئەمانە تێستی دیاریکراوی هەمان کۆمەڵەن، نە ژمارەیەک زیاد لە ٨٨٠ تێستەکە.
- **پێوانەی دوگمەی فاوچەر:** هەردوو دوگمەکە لە دەقی ئاساییدا بەرزی ٤٨dp ـیان هەیە. لە دەقی دوو هێندەدا دوگمەی کۆد ٦٧dp و دوگمەی فاوچەری تەرخانکراو ٥٩dp ـە؛ هەردووکیان گۆشەی ١٨dp ـیان هەیە. بەرزی زیادە بۆ جێگرتنەوەی دەقی گەورەیە. **دوگمەی خەڵاتی ئەرک** لە کۆددا کەمترین بەرزی ٤٨dp و گۆشەی ١٨dp ـی بۆ دانراوە؛ چونکە داتای نمونە ئەرکی تەواوکراوی نییە، ئەو دوگمەیە لەم وێنانەدا پێوانە نەکراوە.
- وێنەکانی سەرەوە لە ویجێتە ڕاستەقینەکانی Flutter و داتای نمونەی کۆنترۆڵکراو دروست کراون. تێستەکان ئەو شاشە، دۆخ و دوگمانە پشتڕاست دەکەنەوە کە لە نمونەکاندا ڕێک خراون؛ بانگەشەی تێستکردنی هەموو مامەڵە بازرگانییەکان یان هەموو ڕێڕەوێکی ئەپ نین.
- **تێستی Android سەرکەوتوو بوو:** ٣٦ دۆخ، ١٬٠٢٣ فریم و ٤٠ وێنە. خانەی ئیمێڵ دوای کرانەوەی کیبۆرد دیار مایەوە؛ ژمارەی مۆبایل و ئاڵا پارێزران. لۆگۆی P لە ئاگاداریی سەر شاشە و پانێڵی ئاگاداریی Android دەردەکەوێت. [وێنە و پێوانەکان](native/README.md). پێوانەی p90/p99 بۆ build بریتییە لە ٣.٠١٧/١٠.٠٢٦ms؛ بۆ raster لە software GPU بریتییە لە ٦٦.٦٠٥/١١٩.١٣٩ms. ئەمانە پشتڕاستکردنەوەی ٦٠fps لە مۆبایلی ڕاستەقینە نین. لە وێنەی native ـی سپڵاشدا ناوی لۆگۆ دەرنەکەوتووە؛ وێنەی تەواوی سپڵاش لە تێستی headless دیارە و ئەم سنوورە لە ڕاپۆرتەکە ڕوون کراوەتەوە.

## ئەوەی هێشتا پێویستە

**OTP ـی ئیمێڵ:** ناردنی کۆد لە API ـەکەتەوەیە: `email.proxopages.com/webhook/send_otp`. ڕێڕەوی دروستکردنی هەژمار و دووبارە ناردنی کۆد بۆ ئەم API ـە چاک کراوەتەوە. Supabase هەژمار و سێشن هەڵدەگرێت و فەنکشنی پشتڕاستکردنەوە جێبەجێ دەکات. داواکاریی پێشووی چالاککردنی Confirm email هەڵە بوو و لابرا؛ ڕێکخستنی ناردنی ئیمێڵەکەت نەگۆڕدراوە. گەیشتنی ئیمێڵی ڕاستەقینە هێشتا تێست نەکراوە. [ڕێڕەوەکان و تێستەکان](email-signup.md).

**ڤیدیۆی فێرکاری:** سێ خانەی ڕێکخستن لە Supabase زیاد کراون، بەڵام هێشتا لینکی ڤیدیۆیان تێدا نییە. ئەدمین دەبێت لینکی ڤیدیۆی ڕاستەقینە دابنێت. [ناوی خانەکان و نمونەکان](form-help.md).

**تێستی ڕاستەقینە:** لەم پشکنینانەدا هەژماری کڕیار دروست نەکراوە و OTP، پارەدان یان push بۆ کڕیار نەنێردراوە. گەیاندنی FCM لە ئینتەرنێت و ڕەفتاری هەموو جۆرە مۆبایلێک بە تێستی ناوخۆیی پشتڕاست نابنەوە.

**APK:** وەشانی چاککراوی `1.0.9+9` دروست کرا و واژۆ، وێنەکان و ڕێکخستنی لۆگۆی ئاگاداری پشکنین کران. واژۆکە debug ـە و فایلەکە بۆ تاقیکردنەوەیە. [بەڵگەی APK](apk-verification.json). کۆی وێنە بڵاوکراوەکان **٢٦٤** ـە. [گۆڕانکاریەکان بە وێنە](changes-and-images.md).
