## Deployment constraints

Production remains on the existing `main@c407dc7` deployment; this PR is draft and unmerged. Earlier automatic approval review rejected changing `autoAssignCustomDomains=false` because of potential live-routing effects, and rejected a reusable protected-preview share URL because anyone holding it could access the preview. Neither decision was bypassed. Exact-head preview/production access must use an approved route before release. The n8n drafts were configured earlier, not published; their configuration-node-only pass is not a full workflow pass.

Release order remains: complete visual/functional verification → preview/staging and backward-compatibility verification → remaining approved migrations/credentials → production build and smoke test → distribute verified release → optional update notice → only later, if justified, raise the supported minimum.
