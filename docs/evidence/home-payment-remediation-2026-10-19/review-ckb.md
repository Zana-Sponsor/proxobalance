## چی گۆڕاوە؟

| بەش | گۆڕانکاری |
|---|---|
| هۆم | سێ کرداری خێرا یەکسان کراون؛ باشترین ئەنجامەکان و کارتەکان بچووکتر و ڕێکخراوترن؛ بەشی پوختە و ئامارە زیادەکانی خوارەوە لابراون. «بینینی ئامارەکان» ماوەتەوە. |
| کارتی باشترین ئەنجامەکان | «وردەکاری زیاتر» ئامانج، بودجە و زانیارییە دووەمەکان لە هەمان کارت دەکاتەوە و دادەخات. وێنەکان قەبارەی جێگیریان هەیە؛ بۆ وێنەی نەبوو یان شکستخواردوو هەمان پاتەرنی **Proxo**ی بەشی ڕیکلام بەکاردێت. |
| پەڕەکان | چوونە ناو بەشەکە لیستی پەڕەکان دەکاتەوە. دۆخی بەتاڵ، بارکردن و هەڵە جیاوازن. ڕێڕەوی دروستکردن پارێزراوە لە کلیکی دووبارە، گۆڕینی هەژمار و وەڵامی درەنگ. کێشەی سێرڤەری بڵاوکراوە هێشتا چارەسەری کۆتایی پێویستە؛ خوارەوە ڕوونکراوەتەوە. |
| زیادکردنی باڵانس | هەڵبژاردنی شێوازی پارەدان، بڕ، کرێ، کۆی کۆتایی، ڕێنمایی، کۆپیکردنی زانیاری و هاوپێچکردنی پسوولە ڕێکخراون. ناردنی دووبارە و هەڵبژاردنی هاوپێچی هاوکات کۆنترۆڵ کراون. |
| لۆگۆ و ئایکۆنەکان | SVGـەکان لە Solar Outline بە شێوازی یەکگرتوو بەکارهاتوون. لۆگۆی ZainCash نوێ کراوەتەوە؛ سەرچاوەی فەرمیی لۆگۆکانی دیکە تۆمار کراوە. بۆ Asiacell، سەرچاوەکە لە پشکنینی نوێدا 503 بوو؛ بۆیە نوسخەی پێشتر پشتڕاستکراوە پارێزراوە و بە «نوێترین» ناونەنراوە. |
| AppBar و مینوو | لۆگۆ، زەنگ و مینوو هاوسەنگ کراون؛ مینوو دەکرێت بسکرۆڵێت و دەرچوون/گواستنەوە لە کلیکی دووبارە و وەڵامی درەنگ پارێزراون. |
| پرۆفایل | ناسنامە، باڵانس، ڕیزەکان، دووگمەکان، دەستکاری وێنە و ئیمێڵ، پشتیوانی و دەرچوون نوێ کراونەتەوە. ناوی درێژ، زانیاریی نەبوو، دەقی گەورە و کیبۆرد تێست کراون. ئایکۆنی کامێرا بەتەواوی لە ناو سنووری وێنەکە دەردەکەوێت. |
| ڕیکلامی بەتاڵ | «هیچ ڕیکلامێک نییە»، «هیچ ئەنجامێک لەم فلتەرەدا نییە»، بارکردن و هەڵە جیا کراونەتەوە. دووگمەی دروستکردنی ڕیکلام یان پاککردنەوەی فلتەر بە دۆخەکە دەگونجێت. |
| پسوولەکان | پسوولەی ڕیکلام و مامەڵەی پارەدان: سەردێر، زانیاری، ژمارە، بڕی پارە، بۆشایی و ڕیزبەندی نوێ کراونەتەوە. PDF هەمان ناوەڕۆکی ڕاستەقینەی ئەپەکە دەپارێزێت و بۆ ناوەڕۆکی درێژ پەڕە زیاد دەکات. |

APIـی ئیمێڵ هەر `https://email.proxopages.com/webhook/send_otp` ـە. ناردنی OTP نەگۆڕدراوە بۆ ئیمێڵی Supabase. تێستەکان ناردنی ئیمێڵی ڕاستەقینەیان نەکردووە.

## تێست و بەڵگە

- [تێستی Android](native/README.md): هەموو 42 دۆخ سەرکەوتوو بوون؛ exception و داواکاریی چاوەڕواننەکراو سفر بوون. 50 سکرینشۆت و پێوانەی 1,562 frame تۆمار کراون. لە emulatorـی software GPU، پێوانەی p90 بۆ build بریتی بوو لە 2.497ms و بۆ raster لە 56.039ms؛ ئەمە بەڵگەی نەرمیی تەواو لە مۆبایلی فیزیکی نییە.
- لۆگۆی Proxo لە [ئاگاداریی باکگراوندی Android](native/background-notification-shade-android.png) پیشان درا و وێنەی گیرا؛ تێستەکە لەسەر دروستکەری ڕاستەقینەی ئاگاداریی ئەپ بوو، بەڵام ناردنی دوورەوەی FCM تاقی نەکرایەوە.
- 119 تێستی پسوولە لە ڕێڕەوێکی نوێدا تێپەڕاند؛ دروستکردنی فۆڵدەری پێوانەکان پێش پاشەکەوتکردن پشتڕاست کرایەوە. 6 تێستی سنووری fixture ـیش تێپەڕاند.
- 204 تێستی کۆتاییی بەشە گۆڕاوەکان سەرکەوتوو بوون؛ دوای چاککردنی داپۆشینی سکرینشۆتەکان، 42 دۆخی گرتنی وێنە دووبارە سەرکەوتوو بوون.
- [تێستی کۆتاییی GitHub CI](ci-results.json) لە هەمان کۆدی APK: **1102 تێستی Flutter سەرکەوتوو بوون**؛ تێستێکی تایبەت بە staging لە ڕانە گشتییەکە skip کرا و لە ڕانە جیاوازەکەدا پشکنرا. هەموو jobـەکانی Flutter، backend، database، responsive و Edge Functions سەرکەوتوو بوون.
- بەشی backend: 179 تێست سەرکەوتوو بوون. ئەمە تێستی جیاکراوەی کۆد و گرێبەستی APIـە، نە بەڵگەی چاکبوونی سێرڤەری بڵاوکراوە.
- 6 تێستی ژینگەی جیاواز پشتڕاستیان کردەوە کە ناردنی ئیمێڵ، پارەدان و Firebaseی بەرهەمهێنان لە staging بانگ ناکرێن.
- پشکنینی کۆدی 49 فایل: هیچ هەڵە یان warningی ڕاگرتنی build نییە؛ 84 تێبینیی شێوازی کۆدنوسین ماونەتەوە.
- پسوولەکان: 108 دۆخ، 1102 ڕیز، 4 PDF و 7 پەڕەی A4. هەموو 22,713,160 پیکسڵی سەرچاوە لە ناو PDF پارێزراون؛ جیاوازی پیکسڵ سفرە.
- وێنەکان لە widgetـە ڕاستەقینەکانی ئەپەکە گیراون، لە 393×852/100٪ و 320×740/200٪. داتای هەژمار و ڕیکلامی تێست دەستکردە؛ ژمارەی وەرگری پارەدان داتای ڕێکخستنی خۆی ئەپەکەیە. هیچ پارەیەک نەنێردراوە.

## APK

[داگرتنی APKـی 1.0.11 لە GitHub](https://github.com/Zana-Sponsor/proxobalance/actions/runs/39391606925/artifacts/12250317662) · [پشکنینی تەواوی فایل و واژۆ](apk/README.md)

فایلەکە 93,142,023 بایتە؛ هەموو 15 پشکنینی کۆتاییی فایل سەرکەوتوو بوون. 185 asset لەگەڵ کۆدی دیاریکراو یەکسانن، لەوانە 12 وێنەی نمونەی پەڕە و SVGـە نوێکان. markerـە دیاریکراوەکانی staging و تێستی native لە APK نەدۆزرانەوە.

ئەمە buildـی releaseـە، بەڵام بە کلیلی **Android Debug**ی CI واژۆ کراوە. واژۆکە لە APKـی پێشووی 1.0.9 جیاوازە؛ بۆیە ناتوانێت ڕاستەوخۆ لەسەر ئەو وەشانە نوێ بکرێتەوە. بۆ نوێکردنەوەی ئەپی کڕیاران، پێویستە هەمان کلیلی واژۆی بڵاوکراوە لە ڕێکخستنی پارێزراوی build بەکاربهێنرێت. هیچ سڕینەوەی ئەپ یان داتای کڕیار بۆ چارەسەرکردنی ئەمە پێشنیار نەکراوە.

## کێشەی دروستکردنی پەڕە و کارە ماوەکان

هۆکارەکە تەنها دیزاین نییە. ئەپی نوێ `page_kind/settings` و ڕێڕەوی نوێی پێشکەشکەرەکان چاوەڕوان دەکات؛ سێرڤەر و schemaی بڵاوکراوە هێشتا گرێبەستی کۆنی `page_type/platforms` بەکاردەهێنن، و endpointی پێویست 404 دەگەڕێنێتەوە. ئەپەکە ئێستا ئەم دۆخە بە هەڵەی ڕوون و دووبارە هەوڵدانەوە پیشان دەدات؛ بە سەرکەوتنێکی ساختە ناوی نابردرێت.

کۆدی client، ڕێڕەوی retry، تۆمارکردنی داواکاری و گەڕاندنەوەی لیست لە تێستی جیاوازدا پشکنراون. بەڵام دروستکردن و ماندنەوەی پەڕە لە سێرڤەری ڕاستەقینە هێشتا پشتڕاست نەکراوەتەوە. پێویستە ژینگەیەکی جیاواز بە schema و APIی هاوتا ئامادە بکرێت و پاش تێستی کۆتایی بڕیار لە بڵاوکردنەوە بدرێت.

داواکاریی پەسەندکردنی تێچووی دروستکردنی ئەو ژینگەیە لەلایەن پێشکەشکەرەوە بە `Invalid or expired requestState` کۆتایی هات؛ هیچ branch یان خەرجییەک دروست نەکرا. [پلانی دیاریکراوی جێبەجێکردن](isolated-rollout-plan.md) و [ڕێنمایی ئامادەکردن](isolated-setup-runbook.md) ئامادەن.

کارت و فلتەری پڕی بەشی ڕیکلام هێشتا سنووردارکردنی کۆنی قەبارەی دەقیان هەیە؛ بەڵگەی 200٪ی ئەم گۆڕانکارییە بۆ دۆخە بەتاڵ/هەڵەکانە، نە هەموو کارتە کۆنەکان. خێرایی ئینتەرنێتی کڕیار، ناردنی ڕاستەقینەی FCM و کارایی مۆبایلی فیزیکی بە تێستی fixture پشتڕاست ناکرێنەوە.
