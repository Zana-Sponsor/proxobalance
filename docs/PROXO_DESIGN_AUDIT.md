# پشکنینی هاوسەنگی دیزاینی Proxo

**بەروار:** ٥ی تشرینی دووەمی ٢٠٢٦
**پڕۆژە:** Proxo Balance — بەشەکانی کڕیار
**ئامانج:** یەکخستنی ڕەنگ، فۆنت، قەبارە، بۆشایی و کۆنتڕۆڵەکان بە شێوازی سادەی ئەپی پڕۆکسۆ.

## مەودای پشکنین

٩ بەش بە سەربەخۆیی پشکنران: Home و فۆڕمی ئاڵوگۆڕ؛ مامەڵەکان و هەڵسەنگاندن؛ پڕۆفایل و باڵانس؛ یاساکان؛ نرخ و گۆڕانکارییەکان؛ پشتگیری؛ ناسنامە؛ هەموو ڕێڕەوەکانی Auth؛ ناڤ، شیت و پەنجەرەکان.

پشکنینی براوسەر **٢٩ دۆخی جیاواز** لە **٨٠ تێکەڵەی دۆخ/قەبارەی شاشە** ئەنجام دا. دۆخەکان فۆڕمی ناسنامە، پەسەندکردن، ڕەتکردنەوە، چاوەڕوانی، هەڵە، پەنجەرەی ئەنجام، وەرگرە پاشەکەوتکراوەکان، هەڵبژاردنی وێنە و کۆتایی شیتی هەڵسەنگاندنیان لەخۆ گرت.

## ناهەماهەنگییە چاککراوەکان

CSSی کۆن بە `!important` ڕەنگی هەندێک دوگمەی سەرەکی دەکردە ڕەش یان سپی و قەبارەی سەردێڕەکانیش دەگۆڕی. شیتەکانی دەرەوەی `mainApp` هەمان پێوەری دیزاینیان نەبوو. ئەم کێشانە بە فایلێکی یەکگرتوو، `assets/css/proxo-design-system.css`، کە لە کۆتایی بار دەکرێت چارەسەر کران.

دوگمە چالاکە سەرەکییەکان شینی پڕۆکسۆن؛ دوگمە لاوەکییەکان ڕووی خۆڵەمێشییان هەیە. دوگمەی ناچالاکی باڵانس بە ڕەنگێکی جیاواز پیشان دەدرێت. فۆڕمەکان، شیتەکان، پەنجەرەی ئەنجام و هەڵسەنگاندن هەمان فۆنت و پێوەری قەبارە بەکاردەهێنن.

هێمای هەڵبژاردنی جۆری کێشە لە پشتگیری گەڕێندرایەوە؛ دۆخی هەڵبژاردنی وێنە دیارتر کرا؛ ئایکۆنی ئیمەیڵ بۆ گەڕاندنەوەی هەژمار زیاد کرا. هێماکانی دۆخی ناسنامە و مامەڵەکان پارێزران، نەک هەموویان بە شین بگۆڕدرێن.

ڕیزی هەڵبژاردنی ڕێگای ئاڵوگۆڕ ٥٦ پیکسڵە، چونکە دوو ڕیزی نووسینی هەیە. هەڵبژاردنی وێنە و خانەی تێبینی بە مەبەست بەرزترن. دیزاینی full-bleed و وێنەکانی Authی ئەپی پڕۆکسۆ پارێزراون.

## ئەنجامی پشتڕاستکردنەوە

- **٨٠/٨٠** تێکەڵەی دۆخ/قەبارە تێپەڕین؛ هیچ دەرچوونی ئاسۆیی لە سنووری شاشە یان هەڵەی JavaScript نەبینرا.
- **١٦/١٦** تاقیکردنەوەی تایبەتی دیزاین، ڕێڕەو، یادخستنەوەی هەڵسەنگاندن و باڵانس تێپەڕین.
- پشکنینی سکرۆڵی شیتی مامەڵە دەستگەیشتن بە ئەستێرەکان و دوگمەی ناردنی هەڵسەنگاندنی سەلماند.
- سینتاکسی CSS، JavaScript و build پشکنران. buildی کۆتایی ٣٩ فایلی بەستراوی پێویستی پشتڕاست کردەوە.
- کۆنتراستی سپی لەسەر شینی کردار **٤.٨٧:١**، نووسینی لاوەکی لەسەر سپی **٤.٧٦:١**، و ئەستێرەی هەڵبژێردراو **٤.٦٣:١**یە. ئەمانە پێوانەی ڕەنگە دیاریکراوەکانن، نەک بانگەشەی پشکنینی تەواوی دەستڕاگەیشتنی WCAG.

## سنووری تاقیکردنەوە

پشکنینی براوسەر بە داتای ساختە و وەڵامی APIی ناوخۆیی ئەنجام درا. هەموو ناردنەکان داخراون و سکریپتی ئامار لە ژینگەی تاقیکردنەوە وەستێندراوە. هیچ مامەڵە، هەڵسەنگاندن یان ناسنامەی ڕاستەقینە نەنێردراوە. ئەم ئەنجامانە تاقیکردنەوەی ڕاستەقینەی OTP، پارەدان یان هەموو APIەکانی backend نین. پانێڵی ئادمین لەم وەشانەدا دیزاینەکەی نەگۆڕدراوە.

## دووبارەکردنەوەی پشکنین

تاقیکردنەوەی تایبەت:

```bash
node --test test/exchange-design-system.test.js test/exchange-proxo-shell.test.js
```

تاقیکردنەوەی براوسەر لەگەڵ سێرڤەری ناوخۆی SPA و Playwright:

```bash
PROXO_PLAYWRIGHT_MODULE=/path/to/playwright \
PROXO_BROWSER_EXECUTABLE=/usr/bin/chromium \
PROXO_TEST_ORIGIN=http://127.0.0.1:8765 \
node test/exchange-design.browser.mjs verified
```

سکریپتەکە تەنها ڕێگە بە localhost دەدات و ناردنی داتا ڕێگری دەکات. ئەنجامی پێوانە و وێنەکان لە فۆڵدەری کاتی `proxo-design-audit` تۆمار دەکرێن.
