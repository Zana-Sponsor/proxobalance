**فایلەکان:**

- `assets/css/auth-balance.css` (`?v=4`)

**چی گۆڕا:**
- **ئایکۆنی نوێکردنەوە** (`#authRefreshBtn`): ئایکۆنە دوو تیرە قورسەکە گۆڕدرا بە تیرێکی بازنەیی ساکار. ئێستا هەمان قەبارە و ئەستووری تیری گەڕانەوەی تەنیشتی هەیە (22px، stroke 1.8).
- **نموونەی ناو خانەکان (placeholder):** ئیتر هیچ نموونەیەک ناوی خانەکە دووبارە ناکاتەوە، و هەموویان کورت و یەکسانن:

| خانە | پێشتر | ئێستا |
|---|---|---|
| `authPass` | وشەی نهێنی | وشەی نهێنییەکەت بنووسە |
| `authName` | ناوی تەواو | بۆ نموونە: زانا ئەحمەد |
| `signupConfirmPass` | دووبارە بنووسە | هەمان وشەی نهێنی بنووسەرەوە |
| `fpNewPass` | وشەی نهێنیی نوێ — کەمترین ٦ پیت | کەمترین ٦ پیت |
| `fpConfirmPass` | دووبارە وشەی نهێنیی نوێ | هەمان وشەی نهێنی بنووسەرەوە |

- **ئاراستەی نموونەکان:** خانەکانی وشەی نهێنی `dir="ltr"` ـن، بۆیە نموونە کوردییەکانیان لە لای چەپ دەکەوتن. ئێستا تا خانەکە بەتاڵ بێت، نموونەکە لە لای ڕاستە (`:placeholder-shown`). کاتێک کڕیار دەست بە نووسین دەکات، وشەی نهێنییەکە وەک پێشتر لە چەپەوە دەنووسرێت. نموونەی ئیمەیڵ (`example@gmail.com`) بە لاتینییە، بۆیە لە چەپ ماوەتەوە.

## ٩. Splash screen ـی خێراتر و کردنەوەی نەرم (v26)

**بەروار:** 2026-11-14 15:13

**فایلەکان:**
- `index.html`: CSS ـی ناو `<style>` ـی سەرەوە، لە `#appSplash` تا `spIn`. هەروەها `app.js?v=82`.
- `assets/js/app.js`:
  - `dismissAppSplash` لە ناو `DOMContentLoaded` گۆڕاوە.
  - لە `startApp` ـدا بانگکردنی `window.__dismissAppSplash()` زیاد کراوە، ڕاستەوخۆ دوای `navigate(routeFromLocation(), false)`.
- `test/exchange-design-system.test.js`: بەهاکانی splash بۆ بەها نوێیەکان نوێ کرانەوە.
- `.github/workflows/exchange-production-smoke.yml`: `animation:spIn 1.15s` گۆڕدرا بۆ `animation:spIn .45s`.

**چی گۆڕا:**

| | پێشتر | ئێستا |
|---|---|---|
| کەمترین ماوەی splash | 1400ms | 500ms |
| جووڵەی لۆگۆ | 1.15s، گەورەبوون و بچووکبوونەوە (bounce) | 0.45s، دەرکەوتنی ئارام (`scale(.92)` → `1`) |
| چاوەڕێی کڕیاری چووەژوورەوە | تا `startApp` تەواو دەبوو، واتە تا wallets و rates و rewards بار دەبوون | تەنها تا سکرینی ئەپ پیشان دەدرێت؛ داتاکان دوای ئەوە لە پشتەوە بار دەبن |
| زۆرترین ماوە | 4200ms (JS) و 4.8s (CSS) | 2500ms (JS) و 3s (CSS) |
| ڕۆیشتنی splash | fade ـی 0.32s | fade ـی 0.35s، و ئەپەکە لە هەمان کاتدا بە نەرمی دەردەکەوێت (`body.app-entering`) |
| ڕووکاری تاریک | splash هەمیشە سپی بوو | `#0b1220`، بۆیە هیچ درەوشانەوەیەکی سپی نییە |

**تێبینی:**
- دەرکەوتنی ئەپەکە تەنها `opacity` بەکاردەهێنێت، نەک `transform`. ئەگەر `transform` بەکاربهێنرایە، شریتی خوارەوەی ئەپ (`position: fixed`) لە کاتی جووڵەکەدا لە جێی خۆی دەجووڵا.
- پێوانی ڕاستەقینە لە وێبگەڕدا: بۆ کڕیارێک کە نەچووەتە ژوورەوە، splash 500ms دوای `DOMContentLoaded` دەڕوات. پێشتر 1400ms بوو.

## تێبینی بۆ دیڤلۆپەر

1. **کلیلەکان لە n8n:** کلیلی Wevlix و کلیلی worker ڕاستەوخۆ لە ناو node ـەکاندا نووسراون، وەک node ـە کۆنەکانی OTP. باشترە بگوازرێنەوە بۆ n8n Credentials. کلیلی worker لە Supabase تەنها بە hash پاشەکەوت کراوە (`ex_whatsapp_worker_keys`). بۆ گۆڕینی، کلیلێکی نوێ زیاد بکە و کۆنەکە بکە `active=false`.
2. **`assets/js/transaction-summary-route.js`:** ئیتر بانگ ناکرێت و دەتوانرێت بسڕدرێتەوە.
3. **تاقیکردنەوەکان:**
   - `test/transaction-summary.test.js` و `test/exchange-proxo-shell.test.js` هەموویان سەرکەوتوون.
   - ئەو تاقیکردنەوانەی تر کە سەرنەکەوتوون، پێش ئەم گۆڕانکارییانەش سەرنەکەوتوو بوون. پێشتر ٨٩ بوون، ئێستا ٨٧ن، و هیچ تاقیکردنەوەیەکی نوێ بەهۆی ئەم گۆڕانکارییانەوە نەشکاوە.
4. **`.github/workflows/exchange-production-smoke.yml`:** پشکنینی production دەبێت لەگەڵ ژمارەی نوێی asset ـەکان هاوئاهەنگ بکرێت. لەم وەشانەدا customer bundle `app.js?v=82` ـە؛ بۆ هەر داهاتووێک ئەو cache key ـە لە HTML، workflow و تاقیکردنەوەکان یەکسان نوێ بکەرەوە. پشکنینەکانی admin ـیش بە وەشانی ڕاستەقینەی خۆیان بهێڵەوە.
5. **ناردنی نامەی واتسئاپ:** تەنها بۆ ئەو کڕیارانە دەنێردرێت کە ئاگاداری واتسئاپیان چالاک کردووە. هیچ نامەیەکی بازرگانی (marketing) ناردن نییە.
6. **ڕێگای چاکسازی:** لۆگی هەموو نامەکان لە `ex_whatsapp_messages` و لە پەڕەی «نامەکانی واتسئاپ»ی پانێڵدا هەیە. هۆکاری هەڵەکان لە ستوونی `last_error` تۆمار دەکرێت.
